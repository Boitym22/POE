Installation & Running
- Prerequisites
    - Java Development Kit (JDK) 8 or higher
    - Apache NetBeans or preferred IDE
    - JSON Simple Library
    - JUnit 5 (for testing)
- Steps to Run
    - Clone the repository
    - Open project in IDE
    - Compile and run Main.java
    - Run test files using Test Project option
